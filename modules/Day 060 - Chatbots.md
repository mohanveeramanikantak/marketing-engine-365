# Day 060 - Chatbots

## Introduction

A Chatbot is a software application designed to simulate human conversations through text or voice. Chatbots allow businesses to automate communication, answer questions, provide support, and assist users without requiring a human operator.

Today, chatbots are used in:

* Customer Support
* Ecommerce
* Banking
* Healthcare
* Education
* Social Media
* Marketing
* Admissions

Modern AI Chatbots powered by Large Language Models (LLMs) can understand natural language, retrieve information, reason over data, and generate human-like responses.

In college marketing, chatbots can automate:

* Admission inquiries
* Course details
* Scholarship information
* Fee structure
* Campus visits
* Student support

---

# What is a Chatbot?

A Chatbot can be defined as:

> "A software application that interacts with users through text or voice and automatically responds to their queries."

The goal is to:

* Automate communication
* Provide instant support
* Improve user experience
* Generate leads
* Reduce operational costs

# Types of Chatbots

---

## 1. Rule-Based Chatbots

Work using:

* Predefined rules
* Decision trees
* If-Else logic

Example:

```python
if question == "Fees":
    print("Tuition fee is ₹70,000")
```

Advantages:

* Simple
* Fast
* Easy to build

Disadvantages:

* Cannot understand complex queries
* Limited flexibility

---

## 2. Menu-Based Chatbots

Provide menus to users.

Example:

```text
1 → Admissions

2 → Courses

3 → Fees

4 → Placements
```

Users select options instead of typing.

---

## 3. Keyword-Based Chatbots

Detect keywords.

Example:

User:

```text
Tell me about fees
```

Keyword:

```text
fees
```

Bot:

```text
Fee details are ...
```

---

## 4. AI Chatbots

AI Chatbots understand:

* Natural Language
* Context
* User intent

Examples:

* ChatGPT
* Gemini
* Claude

AI Chatbots are powered by:

* NLP
* LLMs
* RAG
* Vector Databases

---

## 5. Voice Chatbots

Communicate through speech.

Examples:

* Siri
* Alexa
* Google Assistant

Components:

* Speech-to-Text
* LLM
* Text-to-Speech

---

## 6. Hybrid Chatbots

Combine:

* Rules
* AI
* APIs

Most enterprise chatbots are hybrid systems.

# Chatbot Architecture

A chatbot consists of multiple components.

```text
User

↓

User Interface

↓

NLP Engine

↓

Intent Recognition

↓

Knowledge Base / Vector DB

↓

LLM / Backend APIs

↓

Response Generation

↓

User
```

* Meaning


# Intent Recognition

Intent represents:

> What the user wants.

Examples:

| User Query                  | Intent     |
| --------------------------- | ---------- |
| Tell me fee details         | Fees       |
| What courses are available? | Courses    |
| Is hostel available?        | Hostel     |
| How to apply?               | Admissions |

---

# Entity Extraction

Entities are important information extracted from text.

Example:

```text

```

Entities:

* Course = AI
* Topic = Fees

# Retrieval-Augmented Generation (RAG)

RAG combines:

* LLM
* External Knowledge Base

Architecture:

```text
User Question

↓

Embedding Model

↓

Vector Database

↓

Relevant Documents

↓

LLM

↓

Answer
```

Advantages:

* Reduces hallucination
* Uses custom data
* Supports PDFs and documents

Examples:

* PDF Chatbot
* College FAQ Bot
* Research Assistant

---

# Multi-Agent Chatbots


* Better specialization
